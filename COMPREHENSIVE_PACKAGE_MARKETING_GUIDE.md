## EXECUTIVE SUMMARY

The START FRA platform offers three distinct fraud risk assessment packages designed to serve organizations of all sizes:

- **Starter:** £795 one-time | Single assessment + PDF report | Sole traders & micro-businesses
- **Professional:** £1,799/year | Training-focused | SMEs 10–100 employees | **MOST POPULAR**
- **Enterprise:** £4,995/year | Real-time dashboard + unlimited scale | Large orgs 100+ employees

All packages are **GovS-013 & ECCTA 2023 compliant** and include the comprehensive 13-module fraud risk assessment.

## ENTERPRISE DASHBOARD SYSTEM

### Real-Time Monitoring Overview

The Enterprise dashboard is a production-grade analytics system built with:
- **Frontend:** 800+ lines React/TypeScript component
- **Backend:** Multiple API endpoints with rate limiting & security
- **Database:** Optimized queries for real-time aggregation
- **Design:** GDS (Government Digital Service) compliance

### Dashboard Components

#### 1. Summary KPI Cards
```
┌─────────────────────────────────────────────┐
│  Total Employees │ Completion Rate │ In Prog │ High Risk │
│      250         │     68%        │   45    │    12    │
└─────────────────────────────────────────────┘
```

#### 2. Status Breakdown Chart
- Visual pie chart showing:
  - Completed assessments (green)
  - In Progress assessments (blue)
  - Not Started assessments (gray)
- Real-time update every 5 minutes

#### 3. Risk Distribution Chart
- Horizontal bar chart showing:
  - High Risk employees (red)
  - Medium Risk employees (orange)
  - Low Risk employees (green)
  - Not Yet Assessed (gray)
- Actionable insights for prioritization

#### 4. Multi-Dimensional Filtering
```
Search:     [Type name or email...        ]
Status:     [All Statuses        ▼]
Risk Lvl:   [All Risk Levels     ▼]
Department: [All Departments     ▼]
```

#### 5. Employee Data Table
```
Columns: Name | Email | Department | Status | Risk | Assessments | Completed Date
Rows:    Expandable (click to see detail)
Footer:  [Export CSV] [Refresh] [Total employees filtered]
```

#### 6. Expandable Employee Details
- Assessment history (dates, statuses)
- Key-pass usage tracking
- Answer count metrics
- Completion timestamps

### Backend API Endpoints

```
GET  /analytics/employees
     → Fetch all employees with status & risk levels
     → Rate limited: 30 req/60s
     → Requires: pkg_full package

GET  /analytics/employees/:userId
     → Detail view of single employee's assessments
     → Requires: pkg_full package & employer/admin role

GET  /analytics/dashboard
     → Organization-wide metrics (assessments, key-passes, purchases)
     → Requires: pkg_full package

GET  /analytics/overview
     → Quick summary statistics
     → Rate limited: 30 req/60s

GET  /reports/generate
     → Generate compliance reports
     → Includes: GovS-013, ECCTA 2023, audit trail
```

### Database Security

All endpoints include:
- ✅ Package entitlement enforcement (PACKAGE_REQUIRED errors)
- ✅ Role-based access control (employer/admin only)
- ✅ Organization boundary validation
- ✅ Rate limiting (prevent abuse)
- ✅ Audit logging (who accessed what, when, from where)
- ✅ IP address tracking
- ✅ User agent logging

│  └─ Tech/Growth org → ENTERPRISE (need unlimited scale)

│  └─ ENTERPRISE REQUIRED (Professional not viable)
│     └─ Real-time dashboard becomes essential
│

   └─ ENTERPRISE (mandatory)
      └─ API integration + Priority support critical

### Right-Sizing Questions

Ask customers these questions:

1. **"How many people do you need to assess?"**
   - <50 → Professional viable
   - 50+ → Enterprise needed

2. **"Do you need real-time visibility?"**
   - No, quarterly checks fine → Professional
   - Yes, need live alerts → Enterprise

3. **"Do you have existing security/GRC tools?"**
   - No → Professional works
   - Yes, want integration → Enterprise

4. **"Is compliance a regulatory requirement?"**
   - Light touch (ECCTA evidence) → Professional
   - Heavy (NHS, Finance, Gov) → Enterprise

5. **"What's your growth plan?"**
   - Stable (50-100 staff) → Professional
   - Scaling (100+ expected) → Enterprise
